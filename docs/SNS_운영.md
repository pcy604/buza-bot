**숏츠가 원본이다.** 대본을 먼저 쓰고 거기서 글을 뽑는다. 대시보드가 이미 세로 대응
(`IS_MOBILE`)이라 화면 소재를 따로 만들지 않는다.

## 2. 언제 올리나

## 3. 전개 골격 — 1카드 = 1문단 = 1포토카드 = 1숏츠컷

대시보드 카드가 콘텐츠 단위다. 줄글로 풀어 쓰지 않는다.

| # | 블록 | 자동화 |
|---|---|---|
| ① | 훅 — 오늘 절댓값이 가장 큰 카드 | 🟡 후보 3개 제시 → 승인 때 선택 |
| ② | 무슨 일이 — 지수·시장 폭 | ✅ |
| ③ | 왜 — 주범 업종·종목·히트맵 | ✅ |
| ④ | 반대쪽 — 버틴 업종·특징주 | ✅ |
| ⑤ | **내 규칙은 뭘 했나** ⭐ | ✅ (`rule_checks` + 원장) |
| ⑥ | 한계 — 이게 틀리는 경우 | ✅ |

**⑤가 전부다.** ①~④는 증권사도 쓴다. "내 규칙이 오늘 무엇을 했나"를 매일 쓸 수 있는 건
실전 원장이 공개된 우리뿐이고, 그래서 억지 CTA 가 필요 없다.
**⑥을 매일 붙이는 게 브랜드다.** 규칙이 맞은 날에 한계를 같이 써야 틀린 날 말이 믿긴다.

해석 문장(예: "자금이 좁은 곳으로 몰렸다")은 자동 생성하지 않는다. 생성기가 1개만 제안하고
승인 때 지우거나 고친다.

## 4. 문체 — 규칙 명세 문체

`stock_screener/CLAUDE.md` 의 공개 문구 규칙을 그대로 따른다. 구어체·질문형·수사 금지.

| 금지 | 대신 |
|---|---|
| "어디서 시작됐는지부터 봅니다" | "간밤 미국 증시가 먼저 무너졌다" |
| "눈여겨볼 건 금입니다" | "통상적인 위험회피 국면과 다른 지점은 금이다" |
| "공포지수" | "변동성지수 VIX" |
| "빚으로 산 물량" | "신용융자 잔고" |
| "~로 읽힙니다" | 단정하거나, 근거를 붙여 "~에 가깝다" |

원칙 넷: 평서 종결(~했다) · 정확한 용어 · 문장 길이에 변화 · 완충어 삭제.
**자막(`text`)과 음성(`say`)은 분리한다.** 음성은 `~습니다` 가 자연스럽고 숫자를 한글로
적어야 TTS 가 제대로 읽는다("−10.7%" → "마이너스 십 점 칠 퍼센트").

실물 예시: `content/sihwang_2026-11-20_v3.json`

## 5. 제품 링크 — 담백하게 맨 끝

CTA 는 **"오늘 수치의 원본 화면"** 한 줄 + URL. 본문에 숫자를 다 보여 준 뒤라 설명이 필요 없다.

| 플랫폼 | 위치 |
|---|---|
| 스레드 | 답글 체인 뒤쪽 (첫 글 링크는 도달이 깎인다) |
| 인스타 | 본문 링크 클릭 불가 → "프로필 링크" 안내 |
| 네이버 | 본문 맨 아래 한 줄 |
| 숏츠 | 영상이 아니라 설명란 첫 줄 |

URL 에 `?src=threads` 등을 붙인다. `access.py` 에 유입 추적이 이미 있다(11-15, 미사용).

### 영상은 한 벌만 만든다

mp4 **하나**를 만들고 유튜브·릴스·스레드에 각각 업로드한다. 업로드 어댑터는 플랫폼당
20줄 안쪽이다. 무거운 건 제작(녹화·TTS·자막·조립) 한 벌뿐이다.

### n8n·MCP 는 쓰지 않는다

- **n8n**: 무인 자동화는 되지만 우리에겐 **중복**이다. 콘텐츠가 Python(`market_report.json`·
  원장·백테스트)에서 나오므로 n8n 이 결국 우리 저장소를 다시 호출해야 한다.
  GitHub Actions 크론이 이미 무료로 돌고 있는데 호스팅할 런타임을 하나 더 늘리는 꼴이다.
  이 프로젝트의 고질병이 "조용히 안 도는 것"인데 디버깅할 자리를 둘로 쪼개는 건 역방향이다.
  커뮤니티 노드 상당수가 Upload-Post 같은 **유료 중개**를 전제한다.
- **MCP**: Claude 가 떠 있어야 동작한다 → **무인 자동화가 아니다.**
  사람이 개입하는 구간(네이버 초기 작업)에만 의미가 있다.

## 8. 규제 경계

금융위 법령해석 기준.

| 상황 | 판정 |
|---|---|
| 불특정 다수에게 **무료** 정보 제공 | 신고 불필요 |
| 플랫폼 광고수익만 · 간헐적 후원 | 신고 불필요 |
| **유료 회원제** 등 직접 대가 | 유사투자자문업 **신고** |
| **특정인 맞춤 + 양방향** | 투자자문업 **등록**(자본금 1억) · 미등록 시 3년 이하 징역 또는 1억 벌금 |

주간 특징주 무료 발행은 대상이 아니다. **위험한 쪽은 "요청 종목 분석"이다** —
특정인 맞춤 + 양방향이기 때문이다. 무료인 지금은 문제가 아니지만 유료화 시점에
가장 비싼 줄이 된다.

**설계**: 요청은 받되(댓글·DM·VOC) **답을 그 사람에게 주지 않고 공개 글로 발행**한다.
회신은 "공개 글에서 다뤘습니다 + 링크". 요청자 이름·상황은 쓰지 않는다.
이러면 단방향·불특정 다수가 유지되고, 요청 하나가 글 하나가 되어 소재도 생긴다.

실전 원장은 **전부 공개**한다(11-22 차니 결정, 11-15 비공개 결정을 뒤집음).
다만 "샀다·팔았다 + 어떤 규칙 때문에"(사실)와 "그러니 당신도 사라"(권유)의 경계는 유지한다.
