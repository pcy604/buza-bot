# R&D 1~4 — 착수 기록 (2026-11-12)

## R&D 1. 뉴스 선별 정답셋 (골드셋)
- 문제: 선별 품질을 👍/👎 로 재려 했지만 3주간 외부 표본 1쌍.
- 장치: `tools/news_goldset.py` + `news-goldset` 워크플로(수동). 후보 사건 전체를 표로 → 사람이 판정 칸에 O/X → `python tools/news_goldset.py score` 가 정밀도·재현율·F1.
- 목표: 사건 50건+ 판정. 기준선 숫자를 먼저 잡고, 이후 선별 규칙 변경은 이 숫자로 비교.

## R&D 2. 한국어 '같은 사건' 묶기
- 문제: 같은 사건을 다른 숫자로 보도(특별배당 4,140억 vs 6,800억)하면 숫자 지문·낱말 겹침 모두 실패.
- 가설: 숫자를 뺀 글자 2-gram 겹침(≥0.4, 공통 3개+)이 조사·어순에 강하다. 예시 쌍 0.43 으로 잡힘, 무관 제목 0.
- 장치: `tools/kr_cluster_exp.py` — 현행 군집 위에 '추가로 합쳐질 쌍'만 표로 → 사람 O/X → 오합침률.
- 운영 반영 기준: 오합침 ≤ 10% · 사건 수 의미 있게 감소. news-goldset 실행 시 한국 종목이 있으면 같이 생성.

## R&D 4. 한국 리포트 7p (사업부문·경쟁사)
- 실측(커밋된 kr 7종): 부문 1개 3종(031980·089970·373220), 경쟁사 비어 있음 5종, 삼성전자 비중 합 108.9%(내부거래 — 정상).
- 조치: ① 단일 부문이면 '주요 제품 등의 현황' 제품별 비중을 쓰도록 프롬프트 규칙 ② 경쟁사는 '경쟁 현황·시장점유율' 절 실명(해외 포함) ③ 비중 검산(0~100, 합 60~130% 밖이면 숫자 비움) ④ 빈칸 문구 '10-K' → '사업보고서(DART)'.
- 남은 것: 다음 자료 갱신 때 PSK·삼성전자·에코프로비엠 3종 재생성 → 차니 눈 검수 → 통과하면 `KR_REPORT_OWNER_ONLY = False`.
