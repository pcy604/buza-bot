01 · 원페이저

buza-bot

🟡 정체
문제
투자 정보(유튜브 인사이트, 미국 상장사 공시·재무)가 여러 곳에 흩어져 있어 종목 하나 파악하는 데 시간이 듦
대상
지금은 나(개인 투자자 겸 엔지니어) 1명. 목표는 나 아닌 사용자 3명
해법
텔레그램 봇 하나로 유튜브 채널 요약 + 미국 상장사 IR/재무 딥다이브를 통합, 전부 무료 인프라로 상시 가동
현재 단계
MVP 가동 중 — GitHub Actions 크론으로 실행, 명령 6개(/yt /add /ir /dd /watch /recap) 동작
다음 마일스톤
외부 사용자 3명이 7일 연속 사용 (Q3 계약, 2026-09-30 점검)
그래서 다음 행동봇 링크를 실제로 외부 1명에게 보내본다 — 아직 나 혼자만 씀
02 · 마스터플랜

지금 → 목표

🟡 B1 완료, B2 미착수
✓

B1 — 멀티유저 구독 + IR/딥다이브

완료조건: 실사용자 1명이 6개 명령 전부 최소 1회 성공 실행 → 충족(본인 기준)
▶

B2 — 온보딩 (관심분야→채널 추천)

완료조건: 외부 사용자 3명이 /start 후 7일 연속 명령 사용 — 미착수, 코드 없음
○

B3 — 수익화 (텔레그램 Stars)

완료조건: 결제 1건 발생 — B2 선행 필요, 착수 조건 미충족
그래서 다음 행동B2 없이는 외부 사용자 3명이 안 모임 — 온보딩 플로우(관심분야 질문→채널 3~5개 추천) 설계부터

🔴 미설계

몇 명이면 의미있나

채널

🟡 안정화됨(1건 구조적 한계 확정) 
flowchart TB
  U["텔레그램 유저"] -->|명령 전송| TG["Telegram Bot API"]
  TG -.->|"getUpdates (평균 ~100분 지연, 확정된 플랫폼 한계)"| CRON["GitHub Actions 크론\n4,19,34,49분"]
  CRON --> RUN["run.py: bot.poll()"]
  RUN --> GATE{"6시간 경과?"}
  GATE -->|Yes| JOBS["engine.refresh/fanout\n+ ir.check_watches"]
  GATE -->|No| SKIP["스킵"]
  RUN --> GEMINI["Gemini 무료티어\n(호출 텀으로 버스트 완화)"]
  JOBS --> GEMINI
  GEMINI --> CARD["card.py Pillow 렌더"]
  CARD --> TG2["텔레그램 발송"]
  RUN --> STATE["로컬 JSON 커밋 (abort+재시도, 실패시 명시적 실패)"]
  STATE --> REPO[("GitHub 레포")]
  REPO -.->|다음 실행이 이어받음| RUN
🔴 크론 지연(확정): guru-digest(60분 설정, 채널)와 실측 비교 — 우리 평균 104분, 채널 평균 136분(더 나쁨). GitHub 무료 스케줄의 플랫폼 한계로 증명됨, 코드로 해결 불가
🟡 YT_PROXY 무료티어(Webshare free): IpBlocked 지속 — 영상직접분석 폴백으로 정상 운영 중(설계상 수용, "미해결"에서 제외)
🟡 Gemini 무료쿼터: 호출 텀 추가로 순간버스트 완화(수정완료). 근본 한도는 그대로라 여전히 취약할 수 있음
🔴 상태커밋 실패 은폐 버그: rebase 충돌 시 조용히 포기하고도 "성공"으로 표시되던 결함 수정(abort+재시도+실패시 명시적 에러)
그래서 다음 행동크론 지연은 "우리 설정 문제"가 아니라 증명된 플랫폼 한계 — 계속 불편하면 상시서버(로컬 PC / Oracle 무료 VM) 전환뿐, 코드로는 더 못 고침

06 · SWOT

강점·약점·기회·위협

🟡

Strength

  • 무료 인프라로 상시가동(PC 꺼져도 동작)유지: 크론 지연만 관리하면 됨
  • 공시 원문 기반 정량 정확성(지어낸 숫자 없음)강화: 세그먼트 트렌드로 더 깊게
  • 만든 사람이 실제로 매일 쓰는 유일한 프로젝트레버리지: 실사용 피드백을 B2 설계에 반영

Weakness

  • 크론 응답 15분~수시간 불규칙완화: 급하면 수동 Run workflow 안내 필요
  • Gemini 무료쿼터가 명령 하나에도 순간고갈됨대응: 호출 텀 넣었으나 유료전환 검토 필요할 수도
  • 뉴스는 헤드라인만, 질적 리서치 폭이 얕음보강: 기사 본문 긁기(무료, 착수 대기 중)

Opportunity

  • 무료 개인 투자리서치 도구 수요 자체는 있음검증: B2로 외부 3명 모아 실증
  • 기존 @buza_alarm 채널과 브랜드 이미 겹침결정필요: 채널 흡수/유지 여부 미정

Threat

  • Gemini 무료티어 정책이 언제든 바뀔 수 있음모니터링: 유료 전환 시나리오 미리 계산해둘 것
  • 유튜브 영상 요약 유료화 시 저작권 그레이존대응: 원본링크·큐레이션 포지셔닝 유지
그래서 다음 행동Weakness 3개가 전부 B2(외부사용자 유치) 이전에 해결해야 할 것들 — 순서상 맞음, 계속

09 · 사용자의 목소리

실사용 마찰

🟡
"컴터 끈 상태에서 써봤는데, yt랑 dd 둘 다 안 되던데??"→ 로컬 PC 데몬 구조의 근본 한계 발견, GH Actions 전환 계기
"dd명령어 안 먹어"→ 쿼터초과 예외를 못 잡아 응답이 영영 안 가던 실제 버그로 판명, 수정함
"오늘 처음 쓰는데 왜 소진돼? 그리고 실행해봤는데 아무 응답 없어"→ 쿼터는 정상 리셋됐고, 진짜 원인은 크론 지연이었음
"돈 얼마 내야되는데?" → "무료로 하자 그럼"→ 비용에 민감, 유료 프록시 대신 무료 폴백 채택
"완전 처음보는 기업이면 무슨 사업을 영위하는 건지... 기본적인 정보가 필요할 거 같아"→ /dd에 회사개요(사업설명+세그먼트) 신설 배경
"진짜 기업 IR에서 설명해주는 것만큼 퀄리티를 높여서... 네이버 블로그나 X, 인스타에 업로드 할 정도로 수준 업그레이드 하고 싶은데 잘 안 된다 ㅜ"→ /dd 품질 요구가 "개인용 요약"에서 "퍼블리시 가능한 IR급 리포트"로 재정의됨. 지금 카드 포맷(짧은 불릿)으론 구조적으로 못 미침 — 별도 설계 필요
그래서 다음 행동마찰 7건 중 6건 해결. 마지막 하나(퍼블리시급 품질)는 포맷 자체를 다시 짜야 하는 큰 주제 — 다음 세션에서 바로 시작
10 · 결정 로그

근거 vs 결과

🟡 4건 중 3건 부분반증

로컬 PC 데몬 → GitHub Actions 크론

부분반증
근거PC 꺼지면 봇도 죽음, 상시가동 필요
예측"15분 크론이면 사실상 즉시 응답에 가까울 것"
실제PC 무관하게는 동작하나, 응답이 1~2시간+ 걸린 사례 확인 — 예측은 틀렸음

Gemini API 키 분리(stock_screener와)

부분검증
근거같은 키를 공유해서 쿼터를 서로 갉아먹고 있었음 발견
예측"새 프로젝트 키면 독립 쿼터라 문제 해결"
실제분리 자체는 확인됐으나(리셋 정상 확인), 명령 하나의 버스트만으로도 다시 소진 — 근본 해결 아님

YT_PROXY를 Webshare 무료티어로

반증
근거유료 대신 무료로 유튜브 IP차단 우회 시도
예측"자막 텍스트뿐이라 데이터량 작으니 무료 1GB로 충분할 것"
실제IpBlocked 지속 — 데이터량 문제가 아니라 IP 자체가 걸러짐. 영상분석 폴백으로 우회 중

/dd를 유료 그라운딩 대신 무료 라이트버전으로

부분검증
근거비용 절감, 자유 소스만으로 충분한 품질 목표
예측"무료 소스 조합으로도 쓸만한 딥다이브가 나올 것"
실제작동은 하나, 사용자가 직접 "더 나은 아웃풋" 요청 — 질적 갭은 인정, 정량 엄밀함으로 방향 재조정 중
그래서 다음 행동"무료로 되겠지"라는 예측이 4건 중 3건 빗나감 — 다음 결정부턴 이 패턴을 기본 가정에 반영할 것
