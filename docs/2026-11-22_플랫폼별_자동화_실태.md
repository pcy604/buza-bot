# 네이버 빼고 다 자동화 되나 — 코드를 읽고 답한다

2026-11-22 · 질문: "인스타 쇼츠 및 게시글, 스레드랑 X 게시글, 유튜브 숏츠는 다 자동화 가능?"

**답: API 는 넷 다 있다. 그런데 지금 코드로 되는 건 '글+이미지' 뿐이고, 영상은 네 플랫폼 전부 코드가 없다.**

추측이 아니라 `social/publish_*.py` 를 전부 읽고 적는다.

---

## 한 장 정리

| | 글 + 이미지 | 영상(숏츠·릴스) | 지금 막는 것 |
|---|---|---|---|
| **스레드** | ✅ 코드 O · 토큰 **살아 있음** | ⚠️ API 는 지원 · **코드 없음** | 영상 코드 |
| **인스타 게시글** | ✅ 코드 O · 토큰 없음 | — | `IG_TOKEN` |
| **인스타 릴스** | — | ❌ **코드 없음** | 릴스 코드 |
| **X 게시글** | ⚠️ 코드 O · 키 없음 | ❌ 코드 없음 | **요금제 변경** (아래) |
| **유튜브 숏츠** | — | ❌ **코드 0줄** | 전부 |

**즉 "글"은 사실상 다 되고(토큰만), "영상"은 네 군데 전부 새로 만들어야 한다.**
숏츠를 원본으로 삼기로 했으니, 실제 남은 일의 대부분이 영상 쪽이다.

---

## 플랫폼별 실태

### 스레드 — 글은 오늘도 가능, 영상만 없다

`social/publish_threads.py` 는 `media_type` 을 `TEXT` · `IMAGE` · `CAROUSEL` 세 개만 쓴다.
답글 체인도 구현돼 있다. 토큰은 지금 살아 있다(`stock_studian` 확인).

Threads API 자체는 `VIDEO` 도 지원한다. **우리 코드가 안 쓸 뿐이다.**
`_container()` 에 `media_type='VIDEO', video_url=...` 분기 한 개를 추가하면 된다. 작은 작업이다.

### 인스타 — 게시글은 코드가 있고, 릴스는 없다

`social/publish_instagram.py` 는 `image_url` 만 쓴다. 그리고 첫 줄에 이렇게 막아 둔다.

```python
if not images:
    raise RuntimeError('instagram: 이미지 없는 게시물은 불가')
```

릴스는 Graph API 에서 `media_type='REELS'` + `video_url` 로 올린다. **그 분기가 없다.**
컨테이너 상태 폴링(`status_code == 'FINISHED'`)은 이미 구현돼 있어서 영상에도 그대로 쓸 수 있다.
영상은 처리가 길어 폴링 횟수(지금 10회 × 5초 = 50초)를 늘려야 한다.

### X — 코드보다 요금제가 문제다

두 가지가 걸린다. 하나는 우리 코드, 하나는 X 쪽 정책이다.

1. **우리 코드가 폐지된 엔드포인트를 쓴다.**
   `publish_x.py` 가 이미지 업로드에 `upload.twitter.com/1.1/media/upload.json` 을 쓴다.
   **v1.1 미디어 업로드는 2025-03-31 자로 셀프서브 티어에서 폐지됐다.** 지금은 v2
   (`POST /2/media/upload`)로 가야 한다. 즉 **이미지를 붙이면 실패할 가능성이 높다.**
   텍스트만 올리는 건 영향이 없다.
2. **무료 티어가 신규 개발자에게 없어졌다.**
   2026-02-06 부로 신규 가입은 종량 과금으로 바뀌었다. 기존 사용자에게 남아 있는
   무료 티어도 미디어 업로드 가능 여부에 관해 보고가 엇갈린다(403 사례 있음).
   코드 주석의 "Free 티어(쓰기 전용, 월 1,500)"는 **낡은 정보다.**

**판단**: X 는 우선순위를 가장 뒤로 두는 게 맞다. 한국어 주식 콘텐츠의 독자가 가장 적은
채널인데, 지금은 돈까지 든다. 차니가 계정을 만들어 보고 실제 티어가 무엇인지 확인한 뒤
결정하면 된다. 그 전에는 코드를 고쳐도 검증할 방법이 없다.

### 유튜브 숏츠 — 코드가 한 줄도 없다

`grep` 으로 확인했다. `googleapiclient` · `videos.insert` 어느 것도 없다.
Data API v3 `videos.insert` 로 업로드하고, 세로 영상 + 60초 이내면 유튜브가 숏츠로 분류한다.
필요한 것은 OAuth refresh token 하나다(최초 1회 사람이 동의 → 이후 무인 갱신).

할당량도 봐 둬야 한다. 업로드 1건에 약 1,600 units, 기본 일일 할당량 10,000 units.
**하루 약 6건이 상한**이다. 우리는 하루 2건이라 문제없다.

## 🔴 네 플랫폼 공통으로 걸리는 것 하나

`social/storage.py` 가 **content-type 을 `image/png` 로 하드코딩**한다.

```python
st.upload(key, p.read_bytes(), {'content-type': 'image/png', 'upsert': 'true'})
```

스레드·인스타는 로컬 파일을 못 받고 **공개 URL** 만 받는다. 그래서 Supabase 공개 버킷에
올려 URL 을 넘기는 구조인데, mp4 를 올려도 `image/png` 로 올라간다.
**플랫폼이 거부한다.** 확장자로 content-type 을 정하도록 고쳐야 한다(5분짜리).

이걸 먼저 고치지 않으면 스레드 영상도 인스타 릴스도 전부 같은 자리에서 막힌다.

## 그래서 할 일 — 영상 쪽이 본체다

| | 할 일 | 크기 |
|---|---|---|
| **V0** | `storage.py` content-type 확장자 기반으로 | 5분 |
| **V1** | `shot.py` 캡처 복구(숨은 라벨 → 카드 제목) + 카드 영역 8개 등록 | 중 |
| **V2** | 세로 녹화 (1080×1920 · 모바일 UA · 스크롤) | 중 |
| **V3** | TTS(`say`) + 자막 번인 + 조립 → mp4 | 큼 · **ffmpeg 설치 선행** |
| **V4** | 유튜브 `videos.insert` + OAuth | 중 |
| **V5** | 인스타 릴스 (`media_type='REELS'`) | 작음 |
| **V6** | 스레드 영상 (`media_type='VIDEO'`) | 작음 |
| **V7** | X — v2 미디어 업로드로 교체 + 티어 확인 | **보류** |

V5·V6 은 V3 이 mp4 를 만들어 낸 뒤에야 의미가 있다. 순서가 중요하다.

## 차니가 해야 하는 것 (코드로 안 되는 것)

| | 무엇 | 왜 |
|---|---|---|
| 1 | **ffmpeg 설치** — `winget install Gyan.FFmpeg` | 영상 조립. 이 PC 에 없다 |
| 2 | **`IG_TOKEN` 발급** (Meta 앱 → 장기 토큰) | 인스타 게시글·릴스 둘 다 |
| 3 | **유튜브 OAuth 클라이언트** (Google Cloud 콘솔) | 숏츠 업로드. 최초 동의 1회 |
| 4 | X 계정 티어 확인 | 돈이 드는지 먼저 알아야 한다 |

**1~3 이 끝나면 네이버를 뺀 네 채널이 전부 무인으로 돈다.**
토큰 60일 만료 알림만 붙이면 사람이 할 일은 하루 2분 승인뿐이다.
